# Научиться учиться / How to Learn

**Учебный проект Яндекс Практикума по HTML и CSS.** Статический многоcекционный сайт о методах эффективного обучения. Проект показывает работу с семантической разметкой, компонентной организацией CSS и анимациями.

> **English:** A static educational landing page focused on semantic HTML, modular CSS (BEM), Flexbox, embedded media, and CSS animations.

## Что реализовано

- Структурированная HTML-страница с тематическими секциями, карточками и ссылками.
- CSS-вёрстка с использованием Flexbox.
- Методология БЭМ; стили организованы по файловой структуре **Nested** (`blocks/` и `pages/`).
- Анимации и трансформации CSS.
- Встраивание видео через `iframe`.

## Стек

`HTML5` · `CSS3` · `Flexbox` · `BEM Nested` · `CSS animations`

## Как посмотреть

Склонируйте репозиторий и откройте `index.html` в браузере. Сборщик и сервер для статической версии не требуются.

## Чему посвящена учебная работа

Проект выполнен в контексте обучения веб-разработке: работа с разметкой, CSS, структурой файлов, переиспользуемыми классами и визуальными эффектами.

**Программа:** [Яндекс Практикум — «Веб-разработчик»](https://practicum.yandex.ru/web/).

*Это учебный проект; он не претендует на статус коммерческого продукта.*
